MATHPASTER GUIDE

How to type math into ChatGPT, Claude and Gemini

Use MathPaster to build an equation visually and insert its LaTeX into your chatbot prompt. It is a free Chrome extension with a math keyboard, so you can write a fraction or matrix without spelling out its structure in words.

For a short expression, plain text such as (x+1)/(x-1) can be enough. A visual editor is useful when you want to check nested notation before sending it. MathPaster helps with input; the AI still does the answering.

Open the editor inside your prompt

  1. Install MathPaster from the Chrome Web Store in a desktop browser.
  2. Open ChatGPT, Claude or Gemini, then click its message input.
  3. Press Ctrl+M on Windows or Linux, or Cmd+M on Mac.
  4. Build your equation with the keyboard or symbol buttons. Check its visual preview.
  5. Press Insert or Ctrl+Enter (Cmd+Enter on Mac). MathPaster inserts LaTeX into your prompt. Add your question and send it yourself.

Three examples you can try

Turn on Auto-Symbols for shortcuts such as sqrt and int. A backslash opens LaTeX command completion; for example, type \sqrt and select the square root suggestion.

A fraction with a square root

x+1x+1

Press / to create a fraction. Fill its numerator, use the arrow keys to move to the denominator, then type sqrt to insert a root. Use Up and Down to navigate the fraction fields. The preview makes the extent of the square root visible.

Equivalent LaTeX to paste manually:

$\frac{x+1}{\sqrt{x+1}}$

A definite integral

∫01x2dx

Type int to insert an integral, or choose it from Calculus. Fill the lower bound with 0, the upper bound with 1 and the expression with x² dx. Navigate between the fields using the arrow keys or click a field.

Evaluate this integral: $\int_0^1 x^2\,dx$

This asks for the integral with exact limits; you do not have to describe the bounds in a sentence.

A 2 × 2 matrix

[1234]

Choose Linear Algebra → [ ] → 2 × 2. Enter 1, 2, 3 and 4, pressing Tab to move between cells. The layout shows which values belong to each row.

Find the determinant of $\begin{bmatrix}1 & 2 \\ 3 & 4\end{bmatrix}$.

Which input method should you use?

MethodUseful whenWhat to check
Plain textThe formula is short and easy to read.Use parentheses to make grouping explicit.
Handwritten LaTeXYou already know the commands.Check braces, bounds and matrix separators.
MathPaster’s visual editorYou want to construct and inspect notation as you type.Check the preview and the inserted prompt before sending.

What if the editor does not open?

Click a normal webpage input first. Chrome does not allow extensions to run on some internal browser pages or on the Chrome Web Store. Check that MathPaster is enabled and that its shortcut is assigned at chrome://extensions/shortcuts. You can also open it through the extension icon.

If a website’s custom input does not accept insertion, use Copy LaTeX and paste into the prompt. The chatbot may display the LaTeX source until it responds; MathPaster does not control how the chatbot renders messages.
