MathPaster: a free math keyboard Chrome extension

MathPaster is a Chrome extension for writing math into AI chatbots. Open its visual equation editor over a webpage, build your expression and insert the generated LaTeX at your cursor.

Use it for fractions, square roots, integrals, sums, limits, Greek symbols and matrices. It is designed for prompts in ChatGPT, Claude and Gemini, and for other webpage inputs that accept text.

Install and start writing

  1. Follow the Chrome Web Store link below and choose Add to Chrome.
  2. Open a chatbot in a desktop browser and click the prompt field.
  3. Press Ctrl+M on Windows/Linux or Cmd+M on macOS, or use the MathPaster extension icon.
  4. Write your equation and press Insert. Your prompt receives editable LaTeX text, not a screenshot.

See the fraction, integral and matrix walkthrough for exact examples. You can also try the browser demo without installing.

What is included for free?

  • The visual equation editor and built-in symbol palettes.
  • Auto-Symbols: type shortcuts such as sqrt, int and sum.
  • Backslash command autocomplete, LaTeX copying and direct insertion.
  • Insert history for your last 20 expressions.
  • Precision and Paper themes, plus editor size and layout controls.

What does optional Pro add?

Pro adds named snippets in folders, custom symbol tabs, and Glass and Vaporwave themes. Core equation entry remains free. See the current subscription and lifetime options. Pro licenses are purchased through Lemon Squeezy and activated in the editor settings.

Browser and website compatibility

MathPaster is distributed through the Chrome Web Store for desktop Chrome. Compatible Chromium browsers such as Edge, Brave, Opera and Vivaldi can also install Chrome extensions. It is not a Firefox or Safari extension, and this is not a mobile app.

The extension handles ordinary text fields and rich editable webpage inputs. Browser-protected pages and some custom inputs restrict insertion. If direct insertion fails, use Copy LaTeX and paste it yourself. Website changes can affect compatibility; report an input that does not work.

What MathPaster does—and what your chatbot does

MathPaster creates notation. It does not solve the equation, choose an AI model or submit the prompt automatically. A clear visual preview can help you spot an incorrect bound or grouping, but the answer from the AI still needs verification.

MathPaster is an independent product. It is not made by or affiliated with OpenAI, Anthropic or Google.

Permissions and equation privacy

The extension requests activeTab and scripting to open its editor on the tab you choose, and storage to remember settings and saved data. Equation editing happens in your browser. Optional Pro activation and license validation contact Lemon Squeezy. When you insert and send a formula to a chatbot, that chatbot’s own policies apply. Read the full privacy policy.
